# Artifact 03 — Signal Governance

The framework uses layered signals.

Each signal has a role:

- entry validation
- profit protection
- risk escalation
- kill switch

## Signal Stack

- A1 — entry validation
- B1 — profit protection
- FB2 — risk escalation
- NF1 — system kill switch
- FA1 — acceleration signal

## Design Principle

Signals are not independent.

They form a governance layer controlling:

- entry confidence
- risk expansion
- exit timing
- system shutdown

## Interpretation

Decision systems require:

- signal hierarchy
- risk control
- environment awareness
