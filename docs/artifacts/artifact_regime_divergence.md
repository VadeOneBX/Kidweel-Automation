# Artifact 02 — Same Signal, Different Environment

## Hypothesis

Signal quality depends on environment.

The same ORB breakout behaves differently across regimes.

## NEG Regime

Observed behavior:

- breakout continuation
- VWAP hold
- trend persistence

## POS Regime

Observed behavior:

- breakout failure
- reversion to VWAP
- range compression

## Interpretation

Signal validity is environment dependent.

Environment classification must precede execution.

## Generalization

This applies beyond markets:

- same creative, different auction behavior
- same feature, different user response
- same tactic, different channel conditions

Environment matters.
