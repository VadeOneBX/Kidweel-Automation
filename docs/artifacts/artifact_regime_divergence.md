# Artifact 02 — Same Signal, Different Environment

## Hypothesis

Signal quality depends on environment.

The same ORB breakout behaves differently across regimes.

## NEG Regime

Observed behavior:

- breakout continuation
- VWAP hold
- trend persistence

POS regime:

- breakout failure
- VWAP magnet
- compression

Conclusion:

Signal validity depends on environment.

Environment classification must precede execution.
