# Lab Overview

This repository is best understood as a **decision systems research lab**.

The work sits at the intersection of:

- experimentation
- market microstructure
- automation design
- signal governance

## Research Spine

The lab studies four recurring questions:

1. How should environment be classified?
2. Which signals remain valid across environments?
3. Which constraints distort outcomes?
4. When does automation become justified?

## Public Framing

For fintech audiences:
- regime-conditioned research framework

For growth audiences:
- environment-aware decisioning

For MBA audiences:
- analytical initiative
- systems thinking
- experimental rigor

The value of the lab is not any one result.
The value is the repeatable research process.
