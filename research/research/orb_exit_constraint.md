# Exit Constraint Experiment

Early testing included a fixed trade exit time.

This constraint was originally introduced to simplify execution windows.

During later testing the exit constraint was removed.

The effect was immediate.

Trades that previously ended prematurely were allowed to resolve naturally.

Many moves continued significantly beyond the earlier forced exit.

The conclusion was straightforward:

Time constraints can suppress valid outcomes.

Removing arbitrary exits allows the system to observe the full behavioral resolution of a breakout.
